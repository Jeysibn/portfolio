Architecture & System Design

Cloud-Backed Portfolio

End-to-end serverless system architecture, automation pipelines, and dynamic counter API.

🎯

Project Purpose

To build a high-performance, cost-effective portfolio that moves beyond static site hosting. It demonstrates production-ready DevOps principles—combining Infrastructure as Code, serverless API design, and automated CI/CD deployment.

⚡

What It Solves

Eliminates server management overhead and monthly idle server costs. By leveraging event-driven serverless architecture, the backend scales down to **close to $0/month at rest** while reliably persisting real-time visitor traffic.

💡 Click diagram to expand in full resolution

Key Highlights

  • Infrastructure as Code: Standardized provisioning using Terraform.
  • Backend API: Azure Functions v2 Python model (`getVisitorCount`).
  • Database: Azure Cosmos DB (NoSQL) for serverless persistence.
  • Automated CI/CD: GitHub Actions for seamless deployment.

Technologies Used

Python 3.11 Azure Functions v2 Azure Cosmos DB Terraform GitHub Actions Tailwind CSS

DevOps & Infrastructure

Homelab GitOps Environment

Automated, self-healing Kubernetes cluster powered by IaC and GitOps pipelines.

🎯

Project Purpose

To build a fully automated, self-healing, and observable Kubernetes homelab using Infrastructure as Code (IaC) and a strict GitOps methodology.

⚡

What It Solves

  • Configuration Drift: Ensures cluster state perfectly matches the Git repository.
  • Manual Deployments: Replaces manual deployments with an automated sync pipeline.
  • Deployment Failures: Catches syntax errors, invalid schemas, and security issues in CI.
  • Service Availability: Highly available local DNS, automated TLS, and distributed storage out-of-the-box.

💡 Click diagram to expand in full resolution

Key Highlights

  • Infrastructure as Code: Automated VM provisioning on Proxmox using Terraform.
  • App-of-Apps Architecture: ArgoCD automatically discovers and deploys hierarchical "waves" of applications.
  • CI/CD Quality Gates: GitHub Actions render Helm templates, validate schemas, and scan for security misconfigurations on push.
  • Separation of Concerns: Clean repository structure separating raw Kubernetes manifests from Helm value overrides.

Technologies Used

Proxmox Terraform K3s ArgoCD GitHub Actions Helm Traefik & Cert-Manager Prometheus & Grafana
